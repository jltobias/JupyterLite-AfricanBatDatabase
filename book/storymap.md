# Interactive StoryMap

The [StoryMap](../storymap/) guides readers through each coordinate-valid USGS mine with at least one African Bat Database point within 50 km. A mine page shows its source attributes, nearby records, species labels, locality references, and the number of records in each facility-distance band.

## Using the map

1. Advance or select a facility page.
2. Hover over a bat point to preview its species card; click or tap to keep the card open.
3. Use the radius controls to add or remove nested rings around the mine or the selected bat record.
4. Select another point to move the bat-centered rings. Only one record's rings are shown at a time.

The full-screen StoryMap uses original interface design and a native `.jGIS` story project is included in JupyterLite. Species images are illustrative and credited individually. Diet, foraging ranges, and disease research are shown only when supported by a species-specific source; proximity is never used as evidence for disease transmission.
