# Interactive StoryMap

The [StoryMap](../storymap/) guides readers through each coordinate-valid USGS 2006 mine, selected USGS 2017 critical-mineral resource feature, and the separately sourced Kibali Gold Mine location with at least one African Bat Database point within 50 km. The 2017 source does not distinguish mines from deposits, districts, or regions, so its points are explicitly labeled as unclassified resource features. A page shows its location source and available attributes, nearby records, species labels, locality references, and record counts by distance band.

## Using the map

1. Advance or select a mine or resource-feature page.
2. Hover over a bat point to preview its species card; click or tap to keep the card open.
3. Use the radius controls to add or remove nested rings around the selected location or bat record.
4. Select another point to move the bat-centered rings. Only one record's rings are shown at a time.

The full-screen StoryMap uses original interface design and a native `.jGIS` story project is included in JupyterLite. Species images are illustrative and credited individually. Diet, foraging ranges, and disease research are shown only when supported by a species-specific source; proximity is never used as evidence for disease transmission.
